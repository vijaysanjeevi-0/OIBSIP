# Oasis Infobyte Cybersecurity Internship (OIBSIP)

This repository contains the completed tasks for the Security Analyst track of the Oasis Infobyte Internship Program (August – September 2026).

## Completed Tasks

* **Task 1: Basic Network Scanning with Nmap** (`CyberSecurity-Task1-NmapScan`)
  * Target reconnaissance, service versioning (`-sV`), OS detection (`-O`), and open port risk analysis.
* **Task 2: Basic Firewall Configuration with UFW** (`CyberSecurity-Task2-UFWFirewall`)
  * Custom ruleset implementation (SSH/HTTP/HTTPS), active rule verification, and automated deployment script (`ufw_configuration.sh`).
* **Task 4: Network Security Threats Report** (`CyberSecurity-Task4-NetworkThreats`)
  * Technical breakdown, case studies, and mitigation strategies for DoS/DDoS, MITM, IP Spoofing, and DNS Poisoning.
* **Task 5: Social Engineering Attacks Report** (`CyberSecurity-Task5-SocialEngineering`)
  * Analysis of phishing vectors, pretexting, baiting, and employee security awareness training frameworks.
* **Task 6: Patch Management Report** (`CyberSecurity-Task6-PatchManagement`)
  * Vulnerability lifecycle management (CVE tracking), real-world breach case studies, and patch deployment checklists.

## Environment & Tools
* **OS:** Linux (Ubuntu / Kali Linux)
* **Tools Used:** Nmap, UFW, Shell Scripting, Markdown
